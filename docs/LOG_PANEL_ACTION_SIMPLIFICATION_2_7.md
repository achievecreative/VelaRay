# VelaRay 2.7 — 日志操作区简化

## 用户请求

- 移除日志窗口上方重复的“连接 / 切换 / 断开”和“查看运行配置”按钮。
- 移除该操作行中“检查配置”按钮，并用此功能替换服务器列表下方的“分享”按钮。
- 移除日志窗口右上方的状态文字。

## 最终交互

- 顶部工具栏保留动态连接按钮及“查看配置”。
- 服务器列表下方使用“克隆 | 检查配置 | 删除”。检查配置仍绑定既有 `TestClicked`，执行实际 V2Fly 配置验证。
- 检查通过时显示成功提示框，失败继续使用原有错误提示。
- 日志区域直接显示可滚动日志，底部仍保留端口、实时速度、累计流量与运行模式。
- 原来状态标签用于显示的保存提示改写入运行日志；连接状态仍由顶部状态标签呈现。

## 验证

运行 `python scripts/check_log_panel_action_cleanup.py` 以及其他源码检查。Windows MAUI 编译与视觉效果仍需在 Windows SDK 环境核实。
